# OGCSe
(OpenGL C sharp engine)

This was made as a folow-up on my old python engines i made a couple months back, this engine provides just about everything 
the old engines did, but at an acceptable frame rate, due to C# being a lot faster than python and it using the GPU and not using software rendering.

This engine is the result of me following the official OpenTK tutorial until i had a triangle and then also adding a lot of new functionality like, transparent textures, z ordering and some more.

this project is just made as a fun learning exercise and does not have many practical usecases.
